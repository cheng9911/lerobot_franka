> 本文先归纳五条常见论据，再逐条剖析其合理性，兼听则明。


## 一、常见论据速览  
| 序号 | 论据 | 代表工作 |
|---|---|---|
| **1. 策略多样性** | 任务若存在多条等价最优解，高斯策略最多学一条，扩散策略可全学。 | RDT-1B |
| **2. 榜单成绩** | D4RL、具身任务ablation中普遍领先。 | DiffusionQL、Diffusion Policy |
| **3. 不“左右为难”** | 模仿学习数据出现冲突动作时，高斯策略易卡死，扩散策略保留多峰。 | SfBC、DP |
| **4. 行为拟合上限** | 扩散模型能更逼真地复现人类复杂行为。 | Diffusion BC |
| **5. 与视频世界模型兼容** | 视频生成已是扩散范式，策略可直接复用 backbone。 | Diffuser、Decision Diffuser |



## 二、逐条再审视  

### 1. 策略多样性真的是首要需求吗？  
- **稳定性 vs 多样性**：工业/服务机器人更追求可预测、可复现，而非花式解法。  
- **“等价最优”稀少**：大多数任务的最优解在回报意义下严格唯一，多样性往往只存在于次优区间。  

### 2. 榜单领先 ≠ 方法本质优越  
- D4RL 只看累计回报，不衡量多样性；高斯策略后期也能刷高分，却未获同等关注。  
- 存在“新颖性红利”：扩散策略因概念新，实验投入大，产生幸存者偏差。  

### 3. “左右为难”是算法选择问题，非策略表示问题  
- 症结在于 **Forward-KL / MSE 回归** 的 mode-covering 倾向。  
- 改用 **Reverse-KL**（如 SRPO）即可让高斯策略同样多峰，且采样成本远低于扩散。  

### 4. 行为拟合优势确实成立，但落地场景受限  
- 游戏 AI、人机协作确实需要“像人”；然而离散动作（键盘、按钮）难用扩散建模。  
- 鼠标/轮盘等连续域已验证有效，但泛化到通用离散动作仍需额外设计。  

### 5. 与视频世界模型无缝衔接无可反驳  
- 计算开销巨大，目前仍属“重武器”路线；对实时性要求高的场景尚未普及。  



## 三、小结  
单条论据均可商榷，但 **“多峰建模能力 + 与视频生成同构 + 榜单表现”** 的三重合力，使扩散策略成为当下极具吸引力的研究范式。  
审慎地拆解其优势，正是我们定位局限、推动下一步改进的前提。  

> “让扩散策略在好用与好看之间兼得，而非仅仅好看。”
